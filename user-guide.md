В разделе описаны основные операции с заявками. Перед началом убедитесь, что выполнена [установка](installation.md) и команда `init`.

## Жизненный цикл заявки

![Схема статусов заявки: new, in_progress, closed и команды перехода](images/lifecycle.svg)

Новая заявка получает статус **new**. Команда `take` переводит её в **in_progress**, команда `close` — в **closed**. Закрытую заявку изменить нельзя.

## Создание заявки

```bash
python ticketdesk.py add "Установить Office на новый ПК" --author petrova
```

Тема заявки указывается в кавычках, параметр `--author` обязателен. Если `--priority` не задан, используется значение `default_priority` из конфигурации. Результат: `Заявка #2 создана (приоритет: normal, статус: new)`.

## Просмотр списка заявок

```bash
python ticketdesk.py list
python ticketdesk.py list --status new
python ticketdesk.py list --priority high
```

Фильтры можно комбинировать. Если подходящих заявок нет, выводится сообщение «Заявок не найдено.».

## Просмотр одной заявки

```bash
python ticketdesk.py show 1
```

Выводятся все поля заявки: тема, автор, приоритет, статус, время создания и изменения.

## Обработка заявки

1. Найдите нужную заявку: `python ticketdesk.py list --status new`.
2. Возьмите её в работу: `python ticketdesk.py take 1`.
3. После выполнения работ закройте её: `python ticketdesk.py close 1`.

> **Внимание:** повторное закрытие завершится ошибкой «заявка уже закрыта». Это нормальное поведение, см. [справку по кодам завершения](reference.md#коды-завершения).

## Статистика и экспорт

Количество заявок по статусам:

```bash
python ticketdesk.py stats
```

Выгрузка всех заявок в CSV для открытия в Excel:

```bash
python ticketdesk.py export tickets.csv
```

Результат: `Экспортировано заявок: 2 -> tickets.csv`. Файл использует кодировку UTF-8, при импорте в Excel выберите её явно.
