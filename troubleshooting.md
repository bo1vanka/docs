# Устранение неисправностей

**Разделы документации:** [Главная](index.md) | [Быстрый старт](quick-start.md) | [Установка](installation.md) | [Руководство](user-guide.md) | [Справка](reference.md) | [FAQ](faq.md) | [Неисправности](troubleshooting.md)

---

| Сообщение или симптом | Причина | Решение |
|---|---|---|
| `python` не является внутренней командой | Python не установлен или не добавлен в PATH | переустановите Python с опцией **Add Python to PATH** или используйте `python3` |
| `Ошибка: база данных не найдена` | не выполнена команда `init` или неверен `db_path` | выполните `python ticketdesk.py init`, проверьте путь в `ticketdesk.json` |
| `Ошибка: заявка #N не найдена.` | заявки с таким номером нет | проверьте номер командой `list` |
| `Ошибка: заявка #N уже закрыта.` | закрытые заявки не изменяются | создайте новую заявку |
| `invalid choice` в `--priority` или `--status` | указано недопустимое значение | используйте значения из [справки](reference.md#значения-полей) |
| `the following arguments are required: --author` | не указан автор | добавьте `--author ИМЯ` |
| Тема обрезается после первого слова | тема не заключена в кавычки | пишите тему в кавычках: `"Текст темы"` |

Если проблема не решена, проверьте шаги в [Установке и настройке](installation.md) и ответы в [FAQ](faq.md).
