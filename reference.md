Раздел содержит полный перечень команд, параметров и значений. Пошаговые инструкции находятся в [Руководстве пользователя](user-guide.md).

## Формат вызова

```text
python ticketdesk.py [--config ФАЙЛ] [--version] <команда> [параметры]
```

## Команды

| Команда | Параметры | Назначение |
|---|---|---|
| `init` | — | создаёт `ticketdesk.json` и базу данных |
| `add` | `ТЕМА`, `--author` (обязателен), `--priority` | создаёт заявку со статусом new |
| `list` | `--status`, `--priority` | выводит список заявок |
| `show` | `ID` | выводит все поля заявки |
| `take` | `ID` | переводит заявку в in_progress |
| `close` | `ID` | переводит заявку в closed |
| `stats` | — | количество заявок по статусам |
| `export` | `ФАЙЛ` | выгружает все заявки в CSV |

## Значения полей

| Поле | Допустимые значения |
|---|---|
| Приоритет (`--priority`) | `low`, `normal`, `high` |
| Статус (`--status`) | `new`, `in_progress`, `closed` |

## Параметры конфигурации

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `db_path` | строка | `tickets.db` | путь к файлу базы данных |
| `default_priority` | строка | `normal` | приоритет, если не указан `--priority` |

Порядок настройки описан в разделе [Установка и настройка](installation.md#настройка).

## Коды завершения

- `0` — команда выполнена успешно;
- `1` — ошибка выполнения (заявка не найдена, уже закрыта, не найдена база данных);
- `2` — неверные параметры командной строки.

Типичные причины ошибок разобраны в [Устранении неисправностей](troubleshooting.md).

## Структура базы данных

Таблица `tickets`: `id`, `title`, `author`, `priority`, `status`, `created`, `updated`.
