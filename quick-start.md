Раздел помогает за несколько минут создать первую заявку и перевести её в статус «закрыта». Если Python ещё не установлен, сначала выполните [установку](installation.md).

## Что понадобится

- Python 3.8 или новее;
- файл `ticketdesk.py` из папки `app/`;
- терминал (PowerShell, cmd, Terminal).

## Шаги

1. Откройте терминал в папке с файлом `ticketdesk.py`.
2. Инициализируйте систему:

    ```bash
    python ticketdesk.py init
    ```

    Ожидаемый результат:

    ```text
    Создан файл конфигурации: ticketdesk.json
    База данных готова: tickets.db
    ```

3. Создайте заявку:

    ```bash
    python ticketdesk.py add "Не работает принтер в кабинете 12" --author ivanov --priority high
    ```

    Ожидаемый результат: `Заявка #1 создана (приоритет: high, статус: new)`.

4. Посмотрите список заявок:

    ```bash
    python ticketdesk.py list
    ```

5. Возьмите заявку в работу и закройте её:

    ```bash
    python ticketdesk.py take 1
    python ticketdesk.py close 1
    ```

> **Примечание:** на некоторых системах команда запуска Python называется `python3`. Используйте её, если `python` не найден (см. [Устранение неисправностей](troubleshooting.md)).
