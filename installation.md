Раздел позволяет проверить требования, установить TicketDesk и выполнить первоначальную настройку.

## Системные требования

| Параметр | Минимальное значение | Рекомендуемое значение |
|---|---|---|
| Операционная система | Windows 10, Linux, macOS | Windows 11 / современный Linux |
| Python | 3.8 | 3.11 и новее |
| Оперативная память | 64 МБ | 256 МБ |
| Свободное место | 10 МБ | 100 МБ (с запасом под базу) |
| Дополнительные библиотеки | не требуются | не требуются |

> **Важно:** TicketDesk использует только стандартную библиотеку Python (`argparse`, `sqlite3`, `csv`, `json`), устанавливать пакеты через `pip` не нужно.

## Установка

1. Установите Python с сайта [python.org](https://www.python.org/downloads/). В Windows отметьте пункт **Add Python to PATH**.
2. Проверьте версию:

    ```bash
    python --version
    ```

3. Скопируйте файл `ticketdesk.py` в рабочую папку.
4. Проверьте, что программа запускается:

    ```bash
    python ticketdesk.py --version
    ```

    Ожидаемый результат: `TicketDesk 1.0.0`.
5. Выполните команду `python ticketdesk.py init`.

## Настройка

Параметры хранятся в файле `ticketdesk.json`, который создаётся командой `init`:

```json
{
  "db_path": "tickets.db",
  "default_priority": "normal"
}
```

Файл позволяет изменить расположение базы данных и приоритет, который назначается заявке, если не указан `--priority`. Например, чтобы хранить базу на сетевом диске, замените `db_path` на нужный путь. Описание всех параметров приведено в [справке](reference.md#параметры-конфигурации).

Чтобы использовать другой файл конфигурации, укажите его при запуске:

```bash
python ticketdesk.py --config office.json list
```

## Ограничения

- система однопользовательская: одновременная запись из нескольких мест в один файл базы не рекомендуется;
- нет веб-интерфейса и авторизации;
- удаление и редактирование темы заявки не предусмотрено.

Если при установке возникли проблемы, обратитесь к разделу [Устранение неисправностей](troubleshooting.md).
